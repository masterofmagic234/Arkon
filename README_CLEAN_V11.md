# ACORN HUNTER — CLEAN V11 — QUADMESH REBUILD

Это откат к архитектуре CLEAN V6 как к контрольной точке, но без возврата к проблемной визуальной реализации.

## Что изменено принципиально

1. **Sprite3D полностью убран из игрового мира.**
   - Деревья, белки, жёлуди, шишка, луна и звёзды теперь `MeshInstance3D` + `QuadMesh`.
   - Текстура находится непосредственно в `StandardMaterial3D` этого QuadMesh.
   - Двусторонний рендер (`cull_mode = 2`) и unshaded-материал.
   - Объекты разворачиваются к камере кодом.

2. **Управление больше не зависит от глобального `_input()`.**
   - Джойстик получает `gui_input` непосредственно на своём Control.
   - FIRE работает через сигнал `Button.pressed`.
   - MUTE работает через сигнал `Button.pressed`.
   - Это соответствует доказанному ранее рабочему пути GUI touch.

3. **Музыка — отдельный AudioStreamPlayer в сцене.**
   - MP3 назначен прямо в сцене.
   - `autoplay = true`.
   - FX — отдельный AudioStreamPlayer.

4. **Игровая логика сохранена в духе ТЗ.**
   - 4 жёлудя.
   - 2 белки.
   - Первая пуля по белке оглушает её.
   - Повторные попадания по оглушённой белке считаются промахами.
   - Шишка — ложная цель с шуткой и уроном.
   - HP / AMMO.
   - Carolina в HUD.
   - Миникарта.
   - Музыка, шаги, выстрел, попадание, подбор, урон.
   - Старые смешные фразы возвращены.

## Почему это не очередной патч V10

V10 пытался починить визуальный слой внутри той же модели `Sprite3D + material_override`.
V11 меняет сам способ отображения объектов: **текстурированный QuadMesh становится базовым 3D-примитивом**, а UI-ввод отделён от игровой логики.

## Ограничение проверки

В этой среде нет установленного Godot runtime, поэтому APK на устройстве здесь не запускался. Перед передачей архив проверен статически: пути ресурсов существуют, в сцене нет `Sprite3D`/`material_override`, архив проходит `unzip -t`.
