# Windows-версия

Портативная сборка Windows x64 содержит `AcornHunter.exe`, расположенный рядом `AcornHunter.pck`, инструкцию и лицензии. Распакуйте весь архив в папку; отдельная установка движка, кодеков, Python или FFmpeg не требуется. Выбор графики в главном меню сохраняется между запусками.

Поддерживаемая платформа — Windows 10/11 x64, процессор с SSE4.2 и видеодрайвер с OpenGL 3.3. Vulkan для этой сборки не требуется. Это требования платформы Godot Compatibility, а не подтверждённый замером минимальный компьютер для каждого уровня. 8 ГБ ОЗУ можно взять как начальный рекомендуемый запас для проверки; FPS и достаточность конкретной старой видеокарты нужно измерять на ней.

Слабые встроенные GPU и младшие дискретные карты получают экономный профиль; более мощные карты — баланс или качество. Вручную профиль можно сменить через «ГРАФИКА». В парке отдельно ограничиваются 3D пиксели, мелкая растительность и свет; в погоне — целевой размер изображения машин и декоративная работа; в пиццерии — реальные источники света и эффекты. Частота физики, число противников и правила боя сохраняются.

Управление перечислено в `tools/windows157/README.txt`, который попадает в сборку как `README.txt`. Мобильные клавиши не требуются: используются WASD, мышь и клавиатурные действия. В оконном режиме Windows работает обычная кнопка закрытия окна; неподдерживаемый полноэкранный хоткей не рекламируется.

Сборка выпускается через `.github/workflows/windows_build.yml`. Ubuntu экспортирует настоящий Windows release EXE/PCK из точного исходного дерева и подготавливает проверенные Theora-катсцены. Следующая задача Windows скачивает тот же артефакт, проверяет PE, PCK, контрольные суммы и версии, затем запускает сам EXE с внешними проверочными скриптами. Эти скрипты не входят в игру.

Дополнительно на Windows используется закреплённая версия программного OpenGL Mesa в отдельной тестовой копии. Проверяются реальные кадры трёх уровней в двух профилях и непустое изображение машины. Драйвер и тестовые файлы не добавляются в распространяемый архив. Такие проверки подтверждают работу Windows-пакета и рендеринга, но не измеряют FPS обычной видеокарты.

Сборка не имеет платного сертификата Authenticode. Целостность файлов подтверждается `build-manifest.json`, а целостность скачанного ZIP — каноническим SHA-256 GitHub Actions. Инструкция, лицензия Godot и его сторонние уведомления включены в пакет.
