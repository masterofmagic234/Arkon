ACORN HUNTER — WALLSETS V4

Base: V20 Night Sky Twinkle Walls V3.

Visual-only change: the existing eight 4K rock wall textures are organized into three deterministic visual families and distributed across the canonical 107 wall cells, so the maze has deliberate variation instead of a simple global texture cycle. Geometry, collisions, map, input, gameplay, controllers, GameState, HUD, audio and sky are untouched.

No Godot runtime is installed in the build environment, so runtime/device testing is not claimed here. Archive integrity and resource paths were checked statically.
