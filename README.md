# ACORN HUNTER — Операция «Жёлудь»

Android, Godot 4.7.2, **1.32 / code33**, arm64,
`com.acornhunter.carolina`. Актуальная ветка `fix/level2-final-game-flow`, PR №11.

## Первый уровень — большое лесничество

Одобренный лесной дозор стал первым из **восьми связанных участков**.
Все используют тот же стиль белок, фактурные природные материалы и вечерний свет.
Уровень заканчивается только после всего маршрута и возвращения к машине.

| Участок | Своя задача |
|---|---|
| Лесной дозор | Открытый маршрут, три задачи, первый страж и карта лесничества |
| Яблоневый сад | Сопровождение дружелюбной белки-разведчика до компаса |
| Мельничный пруд | Три шлюза управляют водой, колесом и физической переправой |
| Стеклянный сад | Два зеркала отражают солнечный луч к настоящему цветку |
| Мшистый овраг | Ветер, равновесие на мостах и верёвочный обратный путь |
| Лагерь сборщиков | Укрытия, отвлекающий колокол, тревога и три ящика; бой необязателен |
| Каменный круг | Последовательность рун активируется настоящими выстрелами |
| Древняя роща | Финальный танк с рывком и ударной волной, шесть жёлудей и дорога домой |

В 1.32 все восемь локаций доступны для исследования сразу. Следуй по широкой
тропе к деревянному указателю: проход в лесу переводит в соседнюю локацию
при обычной ходьбе. Не нужно искать кольцо и нажимать «Действие».
Направление, название соседнего места и расстояние видны в HUD; карта рисует
маршрут и отмечает текущее положение. Южные тропы ведут обратно.
У мельницы есть отдельный пешеходный мост, поэтому её головоломка не запирает
весь лес. Задания по-прежнему нужны для завершения уровня: собери все восемь
наград и вернись к машине. Частичную задачу после ухода нужно начать заново;
завершённые задачи и посещения сохраняются. Старое сохранение 1.31 совместимо.
«Продолжить» возвращает в текущую локацию, «Новое приключение» очищает поход.

Телефон: стик, отдельная область обзора, огонь/действие/рывок/тихий шаг.
Карта и пауза освобождают все касания. ПК: WASD, мышь, ЛКМ, E, Shift, C, M, Esc.

Танк — модель владельца проекта, 7,013 треугольников, текстуры1K и 78-костный
скелет; исходник и происхождение в `assets/level1/characters/ASSET_PROVENANCE.md`.
Готовых клипов в исходнике нет: движение рассчитывается по скелету.

## Проверка и сборка

```sh
python3 tools/prepare_intro_videos.py
godot --headless --path . --editor --quit
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_playthrough.gd
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_open_trails_test.gd
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_journey_test.gd
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_journey_rules_test.gd
```

CI отдельно проходит все восемь мест из новой игры без выполнения заданий,
без телепортаций и подготовки сохранения. Также проверяет обе последовательности стартового дозора, все новые участки,
реальный бой, неправильные решения, столкновения, срыв/спасение, управление
картой, контрольные точки и переходы всей кампании. Сохраняются проверки
существующих второго и третьего уровней и вступления.

Два native-фикстурных сценария сохраняют кадры всех участков и мобильного UI.
Лимиты 260 вызовов /150k треугольников включают реальные тени и интерфейс.
На Android загружен один участок, 3D ограничен1280×720 пикселями, UI остаётся
в разрешении телефона. Масштаб восстанавливается перед следующим уровнем.
Программная GPU-проверка не измеряет FPS на реальном телефоне.

APK и кадры публикуются в Actions на14 дней. Старую усадьбу можно открыть
только как справочную сцену; она не является текущим уровнем.
