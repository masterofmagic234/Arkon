# ACORN HUNTER — Операция «Жёлудь»

Android-игра на Godot 4.7.2. Рабочая версия: **1.30 / code 31**, arm64,
пакет `com.acornhunter.carolina`. Актуальная разработка — ветка
`fix/level2-final-game-flow`, открытый PR №11.

## Новый первый уровень: «Лесной дозор»

Компактный лесной парк заменяет прежнюю клеточную усадьбу. Можно выбрать любую
тропу: позвонить в колокол у воды, найти ключ в домике лесника и зажечь фонарь
у старого дуба. Патрули слышат выстрелы и замечают игрока за пределами укрытий.
После трёх задач просыпается белка-танк: уклонитесь от показанного рывка и
стреляйте во время её отдыха. Заберите шесть жёлудей и вернитесь к машине;
посадка по действию продолжает кампанию во втором уровне.

Танк использует новую модель, предоставленную владельцем проекта. Исходник,
происхождение и воспроизводимая оптимизация описаны в
`assets/level1/characters/ASSET_PROVENANCE.md`. Готовых анимационных клипов в
исходнике нет; позы конечностей рассчитываются по его скелету.

Телефон: левый стик — движение, правая область — обзор; огонь, действие,
рывок и тихий шаг имеют отдельные кнопки. Пауза освобождает все касания.
На компьютере: WASD, мышь, ЛКМ, E, Shift, C, Esc.

## Проверка

```sh
python3 tools/prepare_intro_videos.py
godot --headless --path . --editor --quit
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_playthrough.gd
godot --headless --path . --audio-driver Dummy --fixed-fps 60 --script tools/woodland_playthrough.gd -- --reverse-order
```

GitHub Actions дополнительно проверяет столкновения и бой, мобильный ввод,
сохранение/сброс прогресса, переходы всей кампании, второй и третий уровни.
`tools/woodland_visual.gd` сохраняет реальные кадры Forward+, проверяет лимиты
отрисовки с учётом теней и интерфейса, размеры мобильных кнопок и восстановление
масштаба 3D перед следующим уровнем. Старая сцена сохранена только как справка
в `scenes/level1_legacy.tscn`; проверки прежней усадьбы не выдаются за проверки
нового уровня.

Android APK и графические подтверждения публикуются в артефактах Actions на
14 дней. Программная отрисовка CI не измеряет FPS на реальном телефоне.
